# NDX Roadmap

This roadmap is directional, not a promise of delivery dates.

## Stage 0 — Repository foundation
- [x] Public repository and initial project documentation
- [x] Experimental JSON semantic model and schema
- [x] Example document and local validator
- [x] Automated tests and CI
- [ ] Review licensing, governance, and contribution policy

## Stage 1 — Model and specification
- [ ] Define stable element identity and document metadata
- [ ] Specify reading order, language, accessibility, and relationships
- [ ] Design tables, charts, citations, footnotes, and provenance
- [ ] Define extension and compatibility rules
- [ ] Publish normative requirements separately from explanatory notes

## Stage 2 — Core implementation
- [ ] Build robust parser and validator
- [ ] Define resource model and package threat model
- [ ] Add malformed-input and adversarial test corpus
- [ ] Establish interoperability fixtures and conformance tests

## Stage 3 — Reader and authoring
- [ ] Build a reference reader
- [ ] Build authoring workflows
- [ ] Define responsive and page-oriented rendering behavior
- [ ] Add accessibility and localization testing

## Stage 4 — Conversion and ecosystem
- [ ] Prototype HTML and Markdown import/export
- [ ] Evaluate DOCX and PDF import limitations
- [ ] Add conversion reports and warning categories
- [ ] Develop SDKs and CLI tools

## Stage 5 — Independent validation and adoption
- [ ] Independent implementation of the specification
- [ ] External security review
- [ ] Public benchmarks and reproducible results
- [ ] Community governance and standards engagement

A global standard requires independent implementations, transparent governance, interoperability evidence, and sustained community adoption. It cannot be established by this repository alone.
